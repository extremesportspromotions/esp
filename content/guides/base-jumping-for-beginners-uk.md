There is no BASE jump a beginner can book. British Skydiving is the UK governing body for skydiving. Its rules do not cover a jump from a fixed object, and it does not treat that as skydiving [1].

## A first session

There is no first session to book. British Skydiving says there are three ways to make a first jump: the Category System, Accelerated Free Fall, and a tandem [2]. That page describes the climb in the aircraft, then freefall, then the parachute descent [2]. That is a skydive. It is not fixed object jumping [1].

The sports councils' list of recognised sporting activities names British Skydiving for parachuting. It does not list BASE jumping [3].

Our club map shows [some UK BASE jumping clubs](https://esp-lemon.vercel.app/?sport=base-jumping#find-a-club), and it is a starting point rather than a full list.
