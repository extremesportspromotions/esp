There is no BASE jump a beginner can book. British Skydiving is the UK governing body for skydiving. Its rules do not cover a jump from a fixed object, and it does not treat that as skydiving.

## A first session

There is no first session to book. British Skydiving says there are three ways to make a first jump: the Category System, Accelerated Free Fall, and a tandem. That page describes the climb in the aircraft, then freefall, then the parachute descent. That is a skydive. It is not fixed object jumping.

The sports councils' list of recognised sporting activities names British Skydiving for parachuting. It does not list BASE jumping.
